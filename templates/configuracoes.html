Manutenção do sistema

Otimiza o banco de dados e limpa registros antigos pra manter o sistema rápido. Não apaga alunos, comandas nem pagamentos — só faz uma limpeza técnica.

Recomendado rodar de vez em quando (ex.: 1× por mês). Um backup automático é feito antes.

Zerar dados

Apaga todos os dados de alunos, turmas, comandas, ranking e atividade — deixando o sistema como novo. Mantém seus usuários/login e a identidade da arena. Um backup é feito antes. Não dá pra desfazer.
